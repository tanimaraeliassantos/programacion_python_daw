# TIENDA VIRTUAL APP

Tienda Virtual APP es una plataforma de gestión de inventario digital para administrar un catálogo de productos. Su función principal es permitir el control del stock con datos almacenados en una base de datos relacional. El diseño está construido con Bootstrap.

## Características principales de la app:

- Gestión de Productos: Se pueden añadir o eliminar productos, ver y editar detalles de los productos.

- Uso de MySQL para gestionar la información de los productos de manera estructurada.

- Interfaz realizado con Bootstrap.

- Se incorpora Django Rest Framework y con algunas alteraciones en la ruta es posible conectar la plataforma con servicios externos en el futuro.
